# 音ゲーメーカー
音ゲーを簡単に作成できます。

## キー操作

| 操作 | キー | 内容 |
| --- | --- | --- |
| レーン 1 | `D` | 左端のレーンを叩く |
| レーン 2 | `F` | 左から 2 番目のレーンを叩く |
| レーン 3 | `J` | 左から 3 番目のレーンを叩く |
| レーン 4 | `K` | 右端のレーンを叩く |
| 再生 / 一時停止 | `Space` | 音楽の再生・一時停止を切り替える |
| レーンを叩く | クリック / タッチ | 画面のレーンを直接叩く（ロングノートは長押し） |

- 難易度「簡単」は 3 レーンで、`D` `F` `J` を使用します（`K` は使いません）。
- 難易度「普通」「難しい」は 4 レーンで、`D` `F` `J` `K` を使用します。
- ゲーム画面の判定ライン上に、各レーン対応のキーが表示されます。キーを押すと対応するキーが光ります。
